This repository contains the completed Assignment #4 for Front-End Development (Forms and Validation).

## Project Structure
- `part1.html` - Task 0 & 1: Basic HTML Form with built-in HTML5 validation.
- `part2.html` - Task 2 & 3: Bootstrap Form with Grid layout and custom JavaScript validation styles.

- Bootstrap 5 Grid System & Components
- Custom Bootstrap Validation Feedback (`.was-validated`, `.valid-feedback`, `.invalid-feedback`)
- Password matching logic using JavaScript
